How It Works

Convolutional Encoding

Each input bit produces 2 output symbols using shift-register polynomials. This adds controlled redundancy (rate 1/2 = 50% overhead) that allows the decoder to correct errors.

Viterbi Decoding

The Viterbi algorithm finds the most likely original sequence by tracking all possible encoder states simultaneously. Higher K means more states and stronger error correction, but more hardware resources.

Why FPGA?

An FPGA evaluates all 2K-1 states in parallel on every clock cycle. At K=7, that's 64 add-compare-select units running simultaneously — achieving constant-time decoding regardless of message length. Software must loop through states sequentially; the FPGA decodes in microseconds what takes Python tens of milliseconds.

NASA Heritage

These exact polynomials (1718, 1338) were used on Voyager, Mars rovers, and deep-space missions. This FPGA implements the same algorithm in real hardware on a PYNQ-Z2 (Zynq ZC7020), connected live to this page via JTAG.
