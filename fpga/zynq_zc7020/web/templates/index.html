Bulk Decode: an Image Through the FPGA

A grayscale image (up to 160×160) is split into frames of about 120 bytes, convolutionally encoded, hit with the channel error rate set above, and every frame is decoded by the FPGA. The board's ARM core loops the frames through the decoder itself, so the time below is measured on the board: the decoder plus about 2 ms per frame for the ARM to load and read the frame buffer. Network time is not included.

Live Error-Rate Curves measured on the FPGA's on-chip tester

Table view & method

Each point runs N copies of the decoder in parallel inside the FPGA fabric. Every lane has a PRBS-31 data source, the convolutional encoder, and a channel that flips each coded bit with probability p = Q(√(2·R·Eb/N0)) using an xorshift128 random generator. That is exactly what a hard-decision receiver sees for BPSK over AWGN. Decoded bits are compared on-chip against the delayed source bits, and 64-bit counters are read back over AXI. A point stops after 300 decoded errors or 3 s. Theory curves are union bounds computed from each code's distance spectrum. Points with zero errors are drawn as an upper limit at 1/N.

How It Works

Convolutional Encoding

Each input bit produces 2 output symbols using shift-register polynomials. This adds controlled redundancy (rate 1/2 = 50% overhead) that allows the decoder to correct errors.

Viterbi Decoding

The Viterbi algorithm finds the most likely original sequence by tracking all possible encoder states simultaneously. Higher K means more states and stronger error correction, but more hardware resources.

Why FPGA?

This decoder was designed for a Tiny Tapeout ASIC, where area is scarce. It uses a single add-compare-select unit that sweeps all 2K-1 states one per clock cycle, with a sliding-window traceback. On the FPGA the same RTL runs at 50 MHz with fixed, cycle-exact timing. Because it is real hardware, it scales by replication: the error-rate tester runs several independent decoder lanes side by side and measures millions of bits per second, without the CPU touching a single bit. The trellis above is read straight out of block RAM that recorded every add-compare-select result as the chip computed it.

NASA Heritage

These exact polynomials (1718, 1338) were used on Voyager, Mars rovers, and deep-space missions. This FPGA implements the same algorithm in real hardware on a PYNQ-Z2 (Zynq ZC7020), connected live to this page via JTAG. K=9 (5618, 7538) is the rate-1/2 code from IS-95 CDMA and 3GPP.
